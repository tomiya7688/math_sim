# Random tree simulation

A recursive binary branching tree generated by the C++ engine and rendered by the Tkinter parent application.

Each branch creates two child branches. Randomness is applied independently to branch angle and branch length, so the same parameters produce different trees for different seeds.

Parameters:

- `depth`: recursion depth
- `seed`: random seed
- `branch_angle`: base split angle in degrees
- `angle_jitter`: random angle variation in degrees
- `length_decay`: child length / parent length
- `length_jitter`: random relative length variation

The engine outputs normalized line segments as JSON. Rendering is intentionally handled by the Python parent app so the simulation engine remains independent from the UI.
